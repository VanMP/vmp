Case Study: Treatment of Statistical Suppression & Extreme Collinearity in Behavioral Models¶

Este exemplo se baseia no tratamento de um caso real com dados obtidos a partir de uma pesquisa de mercado sobre migração de marca. Os dados foram obtidos de coleta via painel com $N=500$ respondentes, estruturada sob o framework metodológico PPM (Push-Pull-Mooring). Para respeitar a confidencialidade dos dados e do cliente, os nomes das variáveis foram descaracterizados e a ponderação amostral adotada no estudo base foi descartada para este exemplo de portfólio.

1. Theoretical Framework: Push-Pull-Mooring (PPM) Discrete Choice¶

A migração de marca é estruturada sob o modelo comportamental de escolha discreta de Bansal et al. (2005), particionado em três pilares fundamentais:

  • Push (Dores / Fatores de Expulsão): Aversão, problemas de hardware, lentidão, suporte e frustrações acumuladas com o equipamento atual.

  • Pull (Atratividade da Concorrência): Apelo de design, ecossistema, inovação e percepção de superioridade das marcas concorrentes.

  • Mooring (Amarras / Barreiras de Saída): Inércia psicológica, custo financeiro de transição, curva de aprendizado e dependência de periféricos.

2. The Econometric Pathologies Encountered¶

Upon preparing the analytical base, extreme informational overlap across behavioral predictors triggered two major econometric failures:

  1. O Colapso do Push: Quando o modelo hierárquico clássico adiciona a percepção de atratividade da concorrência (Pull), o efeito das dores do produto atual (Push) perde totalmente a significância estatística e inverte seu sinal, sugerindo erroneamente que ter defeitos no produto tornaria o cliente mais fiel à marca.

  2. O Paradoxo do VIF Baixo: O diagnóstico usual de colinearidade via Variance Inflation Factor encontra valores baixos ($\text{VIF} < 2{,}1$), gerando a falsa premissa de que os preditores são ortogonais e descartando o Push prematuramente.

Este notebook documenta o diagnóstico econométrico dessa patologia (Supressão Clássica) e aplica uma Análise de Importância Relativa via Decomposição de Shapley do $\text{Pseudo-}R^2$ de McFadden combinada à Regressão Logística Binária Hierárquica em Blocos Controlada por Covariáveis para resgatar a força explicativa real de cada dimensão.

import pandas as pd
import numpy as np
import statsmodels.api as sm
from sklearn.metrics import roc_auc_score

# 1. Carregar base anonimizada
df = pd.read_csv('dados_ppm_portfolio.csv')

# 2. Função para ajuste de bloco logístico
def rodar_bloco_logit(pred_list, label_modelo):
    y = df['Y_estagio1']
    X = sm.add_constant(df[pred_list])
    n = len(y)
    
    mod_null = sm.Logit(y, np.ones((n, 1))).fit(disp=False)
    mod = sm.Logit(y, X).fit(disp=False)
    
    # Métricas de Ajuste
    ll_null, ll_mod = mod_null.llf, mod.llf
    mcfadden = 1.0 - (ll_mod / ll_null)
    cs = 1.0 - np.exp((2.0 / n) * (ll_null - ll_mod))
    max_cs = 1.0 - np.exp((2.0 / n) * ll_null)
    nagelkerke = cs / max_cs
    auc = roc_auc_score(y, mod.predict(X))
    
    linhas = []
    for var in pred_list:
        coef = mod.params[var]
        se = mod.bse[var]
        pval = mod.pvalues[var]
        sig = '***' if pval < 0.001 else ('**' if pval < 0.01 else ('*' if pval < 0.05 else ('.' if pval < 0.1 else 'ns')))
        linhas.append({
            'Modelo': label_modelo,
            'Preditor': var,
            'Beta': round(coef, 3),
            'SE': round(se, 3),
            'p-valor': round(pval, 4),
            'Sig': sig,
            'Odds Ratio (OR)': round(np.exp(coef), 2),
            'IC 95%': f"[{np.exp(mod.conf_int().loc[var, 0]):.2f} - {np.exp(mod.conf_int().loc[var, 1]):.2f}]"
        })
        
    fit = {
        'Modelo': label_modelo,
        'Log-Lik': round(ll_mod, 2),
        'Nagelkerke R²': f"{nagelkerke*100:.1f}%",
        'McFadden R²': f"{mcfadden*100:.1f}%",
        'AUC-ROC': round(auc, 3),
        'AIC': round(mod.aic, 1)
    }
    return pd.DataFrame(linhas), fit

# 3. Modelos aninhados progressivos
m1_preds = ['z_Push_Global', 'z_idade', 'z_renda', 'z_tempo_posse']
m2_preds = ['z_Push_Global', 'z_Mooring', 'z_idade', 'z_renda', 'z_tempo_posse']
m3_preds = ['z_Push_Global', 'z_Pull_Percepcao', 'z_Mooring', 'z_idade', 'z_renda', 'z_tempo_posse']

c1, f1 = rodar_bloco_logit(m1_preds, 'Modelo 1: PUSH + Controles')
c2, f2 = rodar_bloco_logit(m2_preds, 'Modelo 2: PUSH + MOORING + Controles')
c3, f3 = rodar_bloco_logit(m3_preds, 'Modelo 3: PUSH + MOORING + PULL (Completo)')

print("="*95)
print("📊 PASSO 1: COMPARAÇÃO DE AJUSTE DOS MODELOS HIERÁRQUICOS (N=500)")
print("="*95)
print(pd.DataFrame([f1, f2, f3]).to_string(index=False))

print("\n" + "="*95)
print("📈 PASSO 2: COEFICIENTES E ODDS RATIOS (EVIDÊNCIA DA SUPRESSÃO DO PUSH)")
print("="*95)
print(pd.concat([c1, c2, c3], ignore_index=True).to_string(index=False))

A abordagem classica de literatura para modelos PPM é a análise através de uma Regressão Estrutural Hierárquica em Dois Estágios, onde no primeiro estágio os itens são agrupados em fatores latentes de segunda ordem (push, pull e mooring)

  1. Comparativo entre modelos 1 e 2: Quando os fatores são controlados por mooring (fatores de inércia e custo de troca) o efeito do push (as dores fruto da experiência com o produto) saltam de $OR = 1{,}33$ ($p = 0{,}009$) para $OR = 1{,}81$ ($p < 0{,}001$). Isso ocorre porque as barreiras de saída camuflam a expressão direta do descontentamento do usuário.

  2. Comparativo entre modelos 2 e 3: A inclusão da percepção de pull (atratividade externa da concorrencia), $OR = 3{,}55, (p < 0{,}001$) colapsa o regressor de push para $OR = 0{,}86$ ($p = 0{,}361$), tornando-o estatisticamente nulo e invertendo seu sinal, como se ter problemas no produto posse um fator que leva o usuário a manter a marca.

  3. Implicação Prática: Em uma análise tradicional, o Push seria descartado por falta de significância. No entanto, conforme demonstrado a seguir, essa anulação é fruto da sobreposição informacional ($r = 0{,}689$), e impossibilita uma análise diagnóstica sobre as causas da migração de marca exigindo técnicas de Decomposição de Shapley (Análise de dominância) para que se possa verificar o peso causal real de cada regressor

Aqui, mesmo que tenhamos constatado semanticamente que a analise de regressão classica não faz sentido e verifiquemos que existe uma correlação fortissima (em termos comportamentais, r=0,69 significa variáveis super-hyper ligadas) e que a variável de barreiras (Mooring) tinha correlação negativa com a escolha final ($r = -0{,}18$), mas correlação positiva com os outros preditores ($r \approx 0{,}33$), o fator de inflação da variância encontra um valor plenamente aceitável (<2.1 para todos os preditores).

Existe um problema clássico onde a absorção de variância é causada, não pela inflação na matriz de covariância dos estimadores (VCOV), o que seria detectado pelo VIF, mas sim por fatores que englobam a variável dependente, causados pela relação triangular entre Push, Pull, e o desfecho (intenção de troca ou não de marca).

Para comprovar esse efeito, executamos testes formais de deslocamento de parâmetros e supressão clássica (Conger; Clogg et al.).

# 1. TESTE ANALÍTICO DE SUPRESSÃO DE CONGER (1974)
r_y_push = df['Y_estagio1'].corr(df['z_Push_Global'])
r_y_pull = df['Y_estagio1'].corr(df['z_Pull_Percepcao'])
r_push_pull = df['z_Push_Global'].corr(df['z_Pull_Percepcao'])

produto_indireto = r_y_pull * r_push_pull
diferenca_conger = r_y_push - produto_indireto

print("="*95)

print(f"• r(Y, Pull) * r(Push, Pull)            = {produto_indireto:.4f}")
print(f"• Diferença [r(Y,Push) - Produto]       = {diferenca_conger:.4f}")

# 3. Bootstrap Não-Paramétrico Rápido (B = 1.000)
np.random.seed(42)
B = 1000
n = len(df)
y_arr = y_full.values
X2_arr = X2_full.values
X3_arr = X3_full.values
# Warm-start para rodar em ~1 segundo
start2 = sm.Logit(y_arr, X2_arr).fit(disp=False).params
start3 = sm.Logit(y_arr, X3_arr).fit(disp=False).params
delta_betas = []
for _ in range(B):
  idx = np.random.randint(0, n, n)
  m2 = sm.Logit(y_arr[idx], X2_arr[idx]).fit(
      start_params=start2, maxiter=25, disp=False
  )
  m3 = sm.Logit(y_arr[idx], X3_arr[idx]).fit(
      start_params=start3, maxiter=25, disp=False
  )
  delta_betas.append(m2.params[1] - m3.params[1])
delta_betas = np.array(delta_betas)
ic_low, ic_upp = np.percentile(delta_betas, [2.5, 97.5])
p_boot = np.mean(delta_betas <= 0) * 2
print('=' * 95)
print('📌 TESTE 2: TESTE DE COLAPSO VIA BOOTSTRAP NÃO-PARAMÉTRICO (B = 1.000)')
print('=' * 95)
print(f'• Delta Beta Observado (b_M2 - b_M3): {delta_b:.3f}')
print(f'• Intervalo de Confiança 95% (Boot):  [{ic_low:.3f} a {ic_upp:.3f}]')
print(f'• p-valor do Teste de Supressão:     {p_boot:.4e}')
print('=' * 95)

• p-valor do Teste de Supressão:     0.0000e+00

O teste de Conger comprovou a ocorrencia de supressão clássica entre as variáveis: como o produto das correlações excede a correlação direta [$r(Y, \text{Pull}) \times r(\text{Push}, \text{Pull}) > r(Y, \text{Push})$], a álgebra matricial da regressão força a inversão de sinal do $\beta$ do Push, independentemente do tamanho amostral.

Para testar a significância formal desse colapso contornando a propriedade de não-colapsibilidade da regressão logística (onde a inclusão de regressores afeta a escala latente dos estimadores), aplicamos um Bootstrap Não-Paramétrico com 2.000 replicações:

  • Magnitude do Colapso ($\Delta \beta$): $0{,}749$ (o $\beta$ do Push despenca de $+0{,}594$ para $-0{,}155$)
  • Intervalo de Confiança 95% (Boot): $[0{,}544 \text{ a } 1{,}021]$
  • $p$-valor Empírico: $p < 0{,}0001$ (em nenhuma das 2.000 iterações o $\Delta \beta \le 0$)

Como o intervalo de confiança é estritamente positivo e distante de zero, fica formalmente comprovado que a inversão de sinal do Pushacontece por causa da da sobreposição informacional estrutural com o Pull ($r = 0{,}689$), e não de ausência de poder preditivo real.

Essa sobreposição não é erro de coleta, amostragem ou formulação da pesquisa. Naturalmente, quanto mais problemas e fatores de aversão ao produto da sua marca atual, o comportamento do ser humano é começar a supervalorizar as qualidades em concorrentes.

Para tratar dados com este perfil de sobreposição e colinearidade, adotamos a Decomposição de Shapley sobre o Pseudo-$R^2$ de McFadden (Análise de Dominância). Em vez de forçar as variáveis a disputarem variância em uma única ordem de entrada arbitrária (onde o último a entrar é penalizado), este método calcula a contribuição marginal média de cada fator através de todos os $2^k$ subconjuntos de modelos possíveis ($2^3 = 8$ combinações para os três pilares), particionando o poder explicativo de forma cooperativa e restaurando a importância relativa real e positiva de cada dimensão a 100%.

import math
import itertools
import pandas as pd
import numpy as np
import statsmodels.api as sm
from sklearn.metrics import roc_auc_score

# 1. Configuração dos pilares e controles
pilares = ['z_Push_Global', 'z_Pull_Percepcao', 'z_Mooring']
controles = ['z_idade', 'z_renda', 'z_tempo_posse']
y = df['Y_estagio1']
k = len(pilares)

# 2. Função para cálculo do McFadden R² para qualquer subconjunto
def calcular_mcfadden(vars_subset):
    cols = controles + list(vars_subset)
    X = sm.add_constant(df[cols])
    mod_null = sm.Logit(y, np.ones((len(y), 1))).fit(disp=False)
    mod = sm.Logit(y, X).fit(disp=False)
    return max(1.0 - (mod.llf / mod_null.llf), 0.0)

# 3. Avaliação dos 2^k submodelos possíveis
r2_dict = {}
for r in range(k + 1):
    for combo in itertools.combinations(pilares, r):
        r2_dict[frozenset(combo)] = calcular_mcfadden(combo) if len(combo) > 0 else calcular_mcfadden([])

# Exibir os submodelos avaliados
print("="*95)
print("🔍 SUBMODELOS AVALIADOS (2^3 = 8 Combinações de Predição)")
print("="*95)
for combo, r2_val in r2_dict.items():
    nomes = list(combo) if len(combo) > 0 else ['Apenas Controles']
    print(f"• Submodelo {nomes}: McFadden R² = {r2_val*100:.2f}%")

# 4. Cálculo da Contribuição Marginal Média de Shapley (LMG)
shapley_values = {p: 0.0 for p in pilares}
for p in pilares:
    outros = [x for x in pilares if x != p]
    for r in range(len(outros) + 1):
        peso = (math.factorial(r) * math.factorial(k - r - 1)) / math.factorial(k)
        for sub_combo in itertools.combinations(outros, r):
            s_set = frozenset(sub_combo)
            s_with_p = frozenset(list(sub_combo) + [p])
            marg_contrib = r2_dict[s_with_p] - r2_dict[s_set]
            shapley_values[p] += peso * max(marg_contrib, 0.0)

total_shapley = sum(shapley_values.values())
r2_total = r2_dict[frozenset(pilares)]

# 5. Cálculo das Métricas Globais de Ajuste e Discriminação (AUC-ROC e Nagelkerke)
cols_full = controles + pilares
X_full = sm.add_constant(df[cols_full])
n = len(y)
mod_null = sm.Logit(y, np.ones((n, 1))).fit(disp=False)
mod_full = sm.Logit(y, X_full).fit(disp=False)

ll_null, ll_full = mod_null.llf, mod_full.llf
cs = 1.0 - np.exp((2.0 / n) * (ll_null - ll_full))
max_cs = 1.0 - np.exp((2.0 / n) * ll_null)
nagelkerke = cs / max_cs
auc = roc_auc_score(y, mod_full.predict(X_full))

# 6. Tabela Final de Parts-Worth a 100%
tabela_shapley = pd.DataFrame([
    {
        'Pilar Teórico': 'Push (Dores / Fatores de Expulsão)',
        'Variável': 'z_Push_Global',
        'Contribuição Shapley': round(shapley_values['z_Push_Global'], 4),
        'Importância Relativa (Parts-Worth)': f"{(shapley_values['z_Push_Global'] / total_shapley)*100:.1f}%"
    },
    {
        'Pilar Teórico': 'Pull (Atratividade do Mercado)',
        'Variável': 'z_Pull_Percepcao',
        'Contribuição Shapley': round(shapley_values['z_Pull_Percepcao'], 4),
        'Importância Relativa (Parts-Worth)': f"{(shapley_values['z_Pull_Percepcao'] / total_shapley)*100:.1f}%"
    },
    {
        'Pilar Teórico': 'Mooring (Amarras / Inércia)',
        'Variável': 'z_Mooring',
        'Contribuição Shapley': round(shapley_values['z_Mooring'], 4),
        'Importância Relativa (Parts-Worth)': f"{(shapley_values['z_Mooring'] / total_shapley)*100:.1f}%"
    }
])

Da mesma forma que no primeiro nível, as variáveis micro também são relacionadas entre sí. Aqui adotamos a abordagem Key Driver Analysis com Modelos Bivariados Ajustados por Covariáveis. Cada atributo foi estimado de forma independente, controlando rigorosamente por idade, renda e tempo de posse, garantindo Odds Ratios limpos, estáveis e diretamente comparáveis.

Cada atributo granular foi estimado em regressões independentes, fixando o controle estatístico rigoroso pelas variáveis de perfil:

$$\text{logit}(P(Y=1)) = \alpha + \beta_k \cdot \text{Item}_k + \gamma_1 \cdot \text{Idade} + \gamma_2 \cdot \text{Renda} + \gamma_3 \cdot \text{Tempo de Posse}$$

Neste modelo, apenas 6 dos fatores contém 1 em seu intervalo com confiança a 95% e todos os betas da regressão tem o sinal esperado.

Aqui os rótulos reais e análise sobre os microfatores está suprimida por respeito a acordo de confidencialidade sobre o produto e marca pesquisados, preservando-se integralmente a estrutura matemática, as covariâncias e a interpretabilidade dos estimadores.

Finalizando o estudo: para contornar a sobreposição informacional entre os atributos sem distorcer as propriedades matemáticas dos modelos, adotamos uma abordagem hierárquica em dois níveis

  1. Nível Macro (Dominância Estrutural de 1ª Ordem): A Decomposição de Shapley sobre o $\text{Pseudo-}R^2$ de McFadden divide de forma justa o poder preditivo global do sistema ($55{,}0\%$ Pull, $37{,}3\%$ Mooring e $7{,}6\%$ Push), solucionando a dependência da ordem de entrada e a supressão entre os fatores latentes.

  2. Nível Micro (Key Drivers Bivariados Controlados): Para identificar quais atributos específicos movem a agulha dentro de cada pilar, cada atributo foi estimado de forma independente, controlando estritamente por variáveis sociodemográficas básicas: $$\text{logit}(P(Y=1)) = \alpha + \beta_k \cdot \text{Item}_k + \gamma_1 \cdot \text{Idade} + \gamma_2 \cdot \text{Renda} + \gamma_3 \cdot \text{Tempo de Posse}$$

Dessa forma, os Odds Ratios (OR) e seus Intervalos de Confiança a 95% preservam integralmente sua interpretação probabilística exata (tamanho de efeito por $+1$ desvio-padrão de dor, atração ou barreira), permitindo avaliar simultaneamente a força intrínseca do atributo e a dominância do seu macrobloco.
